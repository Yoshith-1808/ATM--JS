# ATM Simulation System (JavaScript)

A simple console-based ATM (Automated Teller Machine) simulation program written in JavaScript (Node.js) using Object-Oriented Programming (OOP) concepts.

## 🚀 Features

- **Check Balance**: View your current account balance securely after PIN verification.
- **Cash Withdrawal**: Withdraw funds with balance validation and amount checks.
- **Deposit Funds**: Deposit money into the account to update your balance.
- **Change PIN**: Update your existing security PIN securely.

---

## 🛠️ Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your system.

---

## 📦 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Yoshith-1808/ATM--JS.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd ATM--JS
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

---

## 💻 How to Run

Execute the program with Node.js:

```bash
node ATM.js
```

Follow the on-screen terminal prompts to enter your PIN, check balances, deposit, withdraw, or update your PIN.

---

## 🧰 Built With

- **JavaScript (ES6+)** - Core logic implemented using ES6 Classes.
- **Node.js** - Runtime environment.
- **[readline-sync](https://www.npmjs.com/package/readline-sync)** - Synchronous user input via terminal prompts.
